# Тексты для объявлений Авито

Здесь пишем и храним тексты объявлений для Авито: черновики, финальные версии, варианты для A/B-проверки.

## Структура

- `ШАБЛОН.md` — заготовка, с которой начинается каждое новое объявление.
- `объявления/` — готовые тексты, по одному файлу на объявление (`объявления/название-товара.md`).

## Источник фактов

Все цифры в текстах — только из «Ведомости станков для рекламы» с метками ✅ / 📄 и из уточнений, подтверждённых в чате (они отмечены в таблицах фактов). Ведомость в репозиторий не кладём: в ней внутренние цены, а репозиторий публичный.

## Правила, которые держим в голове

**Заголовок**
- До 50 символов, без капса, без цены, без контактов, без «Продам».
- Сначала что это, потом главная характеристика: «Стеллаж металлический 2000×1000, нагрузка 300 кг».

**Описание**
- Первые 2–3 строки — главное: их видно в превью и в поиске.
- Никаких телефонов, почты, ссылок и названий мессенджеров: Авито такие объявления блокирует.
- Без «облака ключевых слов» в конце: за списки посторонних запросов объявление снимают.
- Одно объявление — один товар или одна услуга.
- Короткие абзацы и списки: объявления читают с телефона.
- Эмодзи — только в описании и только как метки разделов и пунктов (✅ ⚡ 📐 🏭 📩), без 🔥 и 💯. В заголовке эмодзи нельзя.

**Перед публикацией**
- Проверить длину заголовка и опечатки.
- Сверить цену, сроки и условия доставки с актуальными.
